# Data Access

The underlying data were collected at a commercial dairy farm and are subject
to access restrictions. Source videos, bbox and tracking data, recording
indexes, full production configs, trained model files, and processed outputs
are not licensed for public redistribution.

Access, when appropriate, must be arranged through the project maintainers and
the internal project data process. Receiving access does not grant permission
to publish, mirror, sublicense, or redistribute the data to another person or
service.

Authorized project members can restore approved private assets from the
internal `Yiwen Huang SNA Project Summer 2026/private_assets/` location. The
public repository contains schema documentation only and no public sample
derived from the restricted farm recordings.
