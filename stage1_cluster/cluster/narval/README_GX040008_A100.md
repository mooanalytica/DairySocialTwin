# GX040008 Narval A100 Run

Copy this `cluster/narval` folder with the project to:

```bash
/home/your_account/scratch/DCSNA
```

From the remote Narval shell:

```bash
cd /home/your_account/scratch/DCSNA
mkdir -p /home/your_account/scratch/DCSNA/run_logs/narval
sbatch /home/your_account/scratch/DCSNA/cluster/narval/run_gx040008_a100.sbatch
```

Watch the newest log:

```bash
tail -f "$(ls -t /home/your_account/scratch/DCSNA/run_logs/narval/dcsna_gx040008_a100_*.out | head -n 1)"
```

```bash
/home/your_account/scratch/DCSNA/input_a100/gx040008/GX040008.MP4
```

pointing to:

```bash
/home/your_account/scratch/V0531/Dairy Farm Videos/May 7 2025 Dairy Farm 3 Videos/Video/Gopro2/GX040008.MP4
```

