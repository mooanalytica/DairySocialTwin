# Latent State Engine (Stage 2) (Neural Relational Inference)

This repository contains the Stage-2 Neural Relational Inference code used after Stage-1 visual perception has already produced per-video CSV files. Stage 2 consumes tracking boxes, keypoints, and manifest metadata to train or evaluate a two-stage cascade:

1. `interaction_gate_2class`: no interaction vs. interaction.
2. `valence_2class`: friendly vs. unfriendly for interacting pairs.

Stage-1 detection, tracking, pose estimation, visualization utilities, and their weights are intentionally not included. Stage-1 weights and CSV generation assets should be obtained from Sibi's Stage-1 project when new Stage-1 outputs are needed.

## Repository Contents

- `train_stage2_nri.py`: trains the Stage-2 NRI cascade and evaluates existing checkpoints on the master-index validation split.
- `run_stage2_from_csv.py`: runs the trained Stage-2 cascade on existing Stage-1 CSV folders and writes interaction outputs.
- `nri_interaction_head.py`: NRI model definitions for the interaction gate and valence head.
- `stage2_pair_features.py`: local pair feature encoding utilities.
- `stage2_dynamic_threshold.py`: cascade threshold calibration and prediction helpers.
- `stage2_index/stage2_master_index.csv`: the committed master index used for dataset-based training and validation.
- `models_new/stage2_interaction_gate_best.pt`: effective interaction-gate checkpoint.
- `models_new/stage2_valence_nri_best.pt`: effective NRI valence checkpoint.

## Environment

The project is intended for the group 5090 workstation. The checked `requirements.txt` reflects the current `~/.venvs/dcsna` environment on that machine.

```bash
cd ~/DCSNA
source ~/.venvs/dcsna/bin/activate
pip install -r requirements.txt
```

Use GPU 1 on the workstation unless the run owner specifies otherwise:

```bash
CUDA_VISIBLE_DEVICES=1 python train_stage2_nri.py --help
```

## Data Paths

The committed `stage2_index/stage2_master_index.csv` is the authoritative training and validation index. It contains absolute paths for the dataset layout used on the workstation. If the dataset is moved, update the CSV paths or pass explicit path arguments where supported.

Some scripts still contain legacy default path strings for older local data roots. These defaults are not part of the recommended workstation workflow; on the 5090 workstation, use `stage2_index/stage2_master_index.csv` for dataset training/evaluation and pass explicit Linux paths for Stage-1 CSV inference.

For `run_stage2_from_csv.py`, set the Stage-1 CSV root explicitly:

```bash
--input-root <stage1_csv_output_root>
```

Each processed Stage-1 folder must contain the existing Stage-1 CSV outputs expected by the script, including `tracking_boxes.csv` and `keypoints.csv`.

## Train Stage 2

Train the default two-stage NRI cascade:

```bash
cd ~/DCSNA
source ~/.venvs/dcsna/bin/activate
CUDA_VISIBLE_DEVICES=1 python train_stage2_nri.py \
  --task two_stage_cascade \
  --stage2-index-csv stage2_index/stage2_master_index.csv
```

The default cascade writes canonical checkpoints under `models_new/` and writes runtime logs under `run_logs/`. Logs and regenerated metric CSVs are not committed.

## Evaluate Existing Checkpoints

Run dataset-based Stage-2 inference on the validation split and write evaluation metrics:

```bash
cd ~/DCSNA
source ~/.venvs/dcsna/bin/activate
CUDA_VISIBLE_DEVICES=1 python train_stage2_nri.py \
  --eval-cascade-only \
  --stage2-index-csv stage2_index/stage2_master_index.csv \
  --interaction-gate-ckpt models_new/stage2_interaction_gate_best.pt \
  --valence-ckpt models_new/stage2_valence_nri_best.pt
```

This evaluation can regenerate confusion matrices and prediction CSVs under `models_new/`. Those generated files are intentionally excluded from the repository.

## Run Stage-2 Inference From Stage-1 CSVs

Run the trained cascade on a directory tree of Stage-1 CSV outputs:

```bash
cd ~/DCSNA
source ~/.venvs/dcsna/bin/activate
CUDA_VISIBLE_DEVICES=1 python run_stage2_from_csv.py \
  --input-root <stage1_csv_output_root> \
  --output-dir output_s2 \
  --interaction-gate-ckpt models_new/stage2_interaction_gate_best.pt \
  --valence-ckpt models_new/stage2_valence_nri_best.pt
```

The inference output directory is regenerated per run and is not committed.

## Regenerated Files

The following files or directories are generated by normal execution and are intentionally omitted:

- `run_logs/`
- `output_s2/`
- `__pycache__/` and `*.pyc`
- `models_new/*_split.csv`
- `models_new/stage2_cascade_val_*.csv`
- `stage2_index/stage2_index_build_summary.json`
- `stage2_index/stage2_split_summary.csv`

The master index is committed directly as `stage2_index/stage2_master_index.csv`; the index-building utility is not part of this trimmed Stage-2 release.
