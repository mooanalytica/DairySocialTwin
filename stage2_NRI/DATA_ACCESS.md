# Data Access and Redistribution

The underlying commercial dairy-farm data used by this project is access-restricted. This includes source videos supplied through MooAnalytica and Agnovix, manual annotations, selected track-pair records, tracking and keypoint CSV files, training indexes and splits, trained model checkpoints, and processed inference or evaluation results.

These assets are not included in the public repository and must not be publicly redistributed. Access is limited to authorized project collaborators and remains subject to the original data agreements. Availability of the source code does not grant permission to access, copy, publish, or redistribute the underlying data or derived private assets.

Authorized collaborators can retrieve private assets from the corresponding location under:

```text
Yiwen Huang SNA Project Summer 2026/private_assets/stage2_NRI/
```

After retrieval, restore each asset to its original project-relative path. Do not include the `MOVE_IT/stage2_NRI/` staging prefix. Contact the project maintainers before sharing any dataset excerpt, annotation, checkpoint, index, or derived result outside the authorized group.
