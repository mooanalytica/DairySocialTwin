# Data Access

The commercial dairy-farm data underlying this project is access-restricted. It
includes source videos, extracted frames, manual annotations, manifests,
metadata, previews, derived results, and any models trained from those materials.

These materials are not licensed for public redistribution and must not be
uploaded to GitHub, attached to public issues or pull requests, or shared with
unauthorized parties. This repository therefore distributes source code and
documentation only and contains no real farm example data.

Authorized research-group members can obtain the private project assets from the
corresponding directory under:

```text
Yiwen Huang SNA Project Summer 2026/private_assets/FloorPlanAnno/
```

Restore private files to their original repository-relative paths, including
`output15/` and `outputs/`. Do not retain an enclosing transfer directory such as
`MOVE_IT/` in the working project layout.

Access requests and questions about permitted uses must be directed to the
research group's data owner or principal investigator. Possession of the source
code does not grant access to, or permission to redistribute, the restricted
data.
