# Data Access

The source code in this repository operates on data collected from a commercial
dairy farm. The underlying data is access-restricted and must not be published,
shared publicly, or redistributed.

Restricted material includes raw and derived video, manual annotations,
tracking boxes, keypoints, identity and re-identification records, cattle
images, full configuration files, trained models, manifests containing private
paths, Stage2/SNA inputs and outputs, and runtime caches derived from those
sources. Processed or cropped material remains restricted even when it does not
contain an entire source video.

Authorized project members obtain the required assets from the internal Dropbox
folder `Yiwen Huang SNA Project Summer 2026/private_assets/` and restore them to
the exact paths documented in the root README. Access requests and questions
about permitted use should be directed to
[Moo Analytica](https://mooanalytica.com/).

Do not add restricted files to Git history, release archives, issue attachments,
or public demonstrations. Only source code, environment files, documentation,
and explicitly approved small public examples belong in this repository.
