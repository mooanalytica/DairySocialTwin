# Quality Control

Quality Control contains two Python scripts for reviewing Stage-2 interaction annotation clips against Stage-1 tracking outputs.

The scripts are intended for local quality-control work on the prepared annotation and Stage-1 data. Generated videos, preview frames, logs, selected-ID CSVs, and cache files are not part of the source package and can be regenerated by running the scripts.

## Files

- `visualize_bbox_roi.py`: builds a visualization index, matches annotation clips to Stage-1 manifests, renders ROI and selected bounding-box overlays, and writes visualization summaries.
- `export_selected_bbox_ids.py`: exports the selected tracking IDs for every frame of each matched clip. It reuses the indexing and selection logic from `visualize_bbox_roi.py`.
- `agents_r.md`: local maintenance instructions for this workspace.

## Dependencies

Use a Python environment with:

- `opencv-python` or another package that provides `cv2`
- `tqdm` for progress bars

Only the Python standard library is otherwise required.

## Data Paths

The current scripts use explicit local paths:

- Annotation clips and annotation CSV index:
  `/home/hyw/Interaction_Annotator-V0601_03_AND_05R`
- Stage-1 tracking and keypoint outputs:
  `/home/hyw/V0604_SEG_S1_TI`

These paths are configured near the top of `visualize_bbox_roi.py`:

- `ANNOTATOR_ROOT`
- `STAGE1_ROOT`

The annotation root is expected to contain `output/index.csv`, `output/annotations`, `output/videos`, and `output/fake_interaction`. The Stage-1 root is expected to contain per-clip `manifest.json`, `tracking_boxes.csv`, and `keypoints.csv` files.

## Outputs

`visualize_bbox_roi.py` writes generated files under `output/`, including rendered MP4 files, preview frames, `visualization_index.csv`, `render_results.json`, and `run.log`.

`export_selected_bbox_ids.py` writes generated files under `output_selected_IDs/`, including one selected-ID CSV per clip, `run_summary.json`, and `run.log`.

These output directories are intentionally excluded from version control. They can be recreated from the external annotation clips and Stage-1 CSV files.

## Usage

Run the visualization script from the project root:

```bash
python -u visualize_bbox_roi.py
```

Build and validate only the visualization index:

```bash
python -u visualize_bbox_roi.py --index-only
```

Export selected tracking IDs:

```bash
python -u export_selected_bbox_ids.py
```

Use `--limit N` on either script to process a smaller number of records.
