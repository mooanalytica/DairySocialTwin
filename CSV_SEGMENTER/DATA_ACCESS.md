# Data Access and Redistribution

The underlying data used with this project originates from commercial farms and is access-restricted. It is not public data and must not be redistributed, republished, mirrored, sublicensed, or uploaded to public services.

This restriction applies to raw recordings and to non-public derived material, including videos, images, tracking boxes, keypoints, identity information, interaction records, manifests containing private metadata, trained models, complete private configurations, annotations, indexes, and processed results.

The public repository contains code and documentation only. Possession of the code does not grant access to the data or permission to reconstruct, share, or redistribute restricted datasets.

Authorized project members must obtain private assets through the research group's approved internal storage. The internal Dropbox location is:

```text
Yiwen Huang SNA Project Summer 2026/private_assets/
```

Assets retrieved from that location must be restored to their original relative directory structure and handled under the project's existing data-use agreements. They must never be committed to the public repository.

This repository does not provide a public data-access application process. Questions about authorization must be directed to the repository maintainers or the project principal investigator through established institutional channels. Access is not guaranteed.
