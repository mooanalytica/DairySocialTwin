# Data Access

This repository does not distribute the underlying commercial dairy-farm
data. Reference frames, source videos, manual zone annotations, annotation
previews, metadata, full configurations, and processed results are restricted
to authorized project members.

Restricted data must not be uploaded to public repositories, shared with
unauthorized parties, or redistributed. Authorized project members should
obtain the required assets from the internal project Dropbox and restore them
using the directory structure documented in `README.md`.
